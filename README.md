## 🧠 How DropSeo Works

```mermaid
flowchart LR
    A[🌐 Website] --> B[👀 Observe]
    B --> C[🧠 Plan]
    C --> D[⚡ Act]
    D --> E[📸 Evidence]
    E --> F[✅ Verify]
    F --> G[📊 Report]
```

---

## ⚡ Agent Loop

```mermaid
flowchart TD
    A[🔍 Observe] --> B[🧠 Reason]
    B --> C[📋 Plan]
    C --> D[🤖 Execute]
    D --> E[📸 Collect Evidence]
    E --> F{✅ Verified?}
    F -- No --> B
    F -- Yes --> G[🚀 Result]
```
